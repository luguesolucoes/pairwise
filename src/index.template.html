Activity

Everything this page does on the network is listed here.
    What this page does on the network
    • The page talks only to its own server, over ordinary HTTPS. Its Content Security Policy limits connections to that same origin, so it cannot reach anywhere else.
    • When you pair, it stores only the encrypted text (AES-256-GCM ciphertext) on the server under a random id, until the link is opened or expires.
    • The decryption key is in the link fragment (after #). Browsers never put the fragment in an HTTP request, so the key never reaches the server.
    • The receiving device retrieves the ciphertext by its id and decrypts it in the browser. If "delete after first download" was set, the server removes its copy once it has been served.
    • The server only ever holds ciphertext and a random id. It cannot read the text.
